A stand-in for a Rails page. The runtime report at the bottom of this document describes what the page rendered and what is wrong with it. The badge docks into the Herb menu in the top right corner and blocks nothing.

The markup carries the same data-herb-debug-* attributes the Herb engine emits, so the View, Partial, Component and ERB Output Outlines toggles in the Herb menu all have something to act on, and the paths they show match the render stacks in the panel.
